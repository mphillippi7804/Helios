Changes made (relative to official Helios 1.6.6200.7) - Helios 1.6.6200.7.4, smaller feature set:
  - Profile Editor: Find All / Replace with results window (Go To, Replace, Replace All)
  - Replacing an object's image keeps the object's size (in the editor)
  - Typing a Width/Height scales a panel's contents proportionally; rotated children scale correctly
  - Group (Ctrl+G) and Ungroup (Ctrl+U)
  - Monitors, panels and their devices listed alphabetically in the Profile Explorer and Bindings panel
  - Build: automatic version numbering (official version + ".4") and GitHub release publishing
  (The full feature set is Helios <version>.5 on the helios-editor branch.)
