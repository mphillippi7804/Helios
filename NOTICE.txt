This version is installed as "Helios Dev Custom" in Program Files\Helios Virtual Cockpit\Helios Dev Custom,
alongside regular Helios; documents, settings and profiles use the normal Helios folders.

Changes made (relative to official Helios 1.6.6200.7):
  - Profile Editor: Find All / Replace with results window (Go To, Replace, Replace All)
  - Profile Editor: Ctrl + mouse wheel zooms toward the pointer; side wheel / Shift + wheel scroll sideways
  - Replacing an object's image keeps the object's size (in the editor)
  - Group (Ctrl+G) and Ungroup (Ctrl+U)
  - Typing a Width/Height scales an object's contents proportionally; rotated children scale correctly
  - Profile Explorer and Bindings panel listed alphabetically
  - Bindings panel: Input and Output combined; grouped into "Input"/"Output" folders and by name
  - Build: automatic version numbering and GitHub release publishing
  - Installer: separate "Helios Dev Custom" product with its own folder, shortcuts and component IDs, so the
    regular Helios installer cannot overwrite or remove it
